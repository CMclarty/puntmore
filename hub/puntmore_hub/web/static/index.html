Scraper

Targets

What targets.toml says, joined to the Scraper's last report. Every change goes through scraper/targets.py (the same rules as python -m scraper targets …); the Scraper applies changes within 60 s. Tap a target's name to see the rows in its latest/<target>.json. “next due” is last load + every_min, give or take the Scraper's jitter (×0.75–1.35).

Edit

Blank clears a field back to its default. Only changed fields are sent. Name, site, mode, parser and post are not edited here: remove and add the target.

Remove

This deletes the target from targets.toml. To stop it for now, disable it instead. Type the target's name to confirm.

Add target

The fields of targets add. A Bet Finder source is site = generic, post = hub:tips. Add it disabled, check its first parse, then enable it. [target.matches] is set with python -m scraper targets set … --matches.

Site budgets

Read-only. A cool-off that needs resume is ended with the Scraper's own command, run on the Hub; the console does not run it.
