Jobs

One row per job in targets.toml: what it is doing now, when it last read rows, how many it has sent. “details” opens its settings, log and actions; the name opens its latest rows. Every change goes through scraper/targets.py and the Scraper applies changes within 60 s.

Edit

Blank clears a field back to its default. Only changed fields are sent. Name, site, mode, parser and post are not edited here: remove and add the target.

How the Scraper behaves

Every limit, timing and click, each declared in scraper/behaviour.py; a change is written to behaviour.toml. Changes apply within 60 s, without a restart. A timing already drawn (a page's next reload or fresh page, the next round of clicks, a back-off, the service's restart) changes from its next draw. Every change is logged (logs/behaviour.log in the Scraper's data, and console-actions.log).

This puts every setting back to its default. Type RESET to confirm.

Site budgets

Read-only. A cool-off that needs resume is ended with the Scraper's own command, run on the Hub; the console does not run it.
